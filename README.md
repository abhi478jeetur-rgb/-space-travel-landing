# Space Travel Landing Page

Cinematic space-travel landing page with two full-height sections featuring looping background videos with custom JS crossfade, liquid-glass design system, and Framer Motion entrance animations.

## Features

- **Hero Section** - Full viewport with animated background video, navbar, badge, headline with blur-text animation, subheading, CTAs, stats cards, and partner logos
- **Capabilities Section** - Full viewport with background video, header, and three feature cards
- **Custom FadingVideo Component** - Pure JavaScript requestAnimationFrame-driven video crossfade (no CSS transitions)
- **Liquid-Glass Design System** - Two variants: `.liquid-glass` (subtle blur) and `.liquid-glass-strong` (heavy blur)
- **Framer Motion Animations** - Entrance animations with blur effects and word-by-word BlurText component

## Tech Stack

- React 18 (CDN)
- Tailwind CSS (CDN)
- Framer Motion (CDN)
- Babel Standalone (CDN)

## Fonts

- Instrument Serif (italic) - Headings
- Barlow - Body text
